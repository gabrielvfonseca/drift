# Security policy

## Supported versions

Only the latest published minor version of `@drift/after` and `@drift/after-react` receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/gabrielvfonseca/drift/security/advisories/new),
or email gabriel@frontal.dev with the subject "drift security".

Include the affected package and version, a description of the impact, and steps to reproduce.
You can expect an acknowledgement within 3 business days and a status update within 10.
Fixes are released as patch versions, and the advisory is published after the fix ships.
